# Data (planned scripts, milestone M1)

- `download.py` — downloads public datasets with pinned URLs and checksums
  (UCI Cleveland Heart Disease, Pima Indians Diabetes).
- `raw/`, `interim/`, `processed/` — git-ignored; only scripts and small metadata are committed.

**Policy:** public, de-identified datasets only. No real personal medical data may ever be
committed to this repository (see `.gitignore` and `CONTRIBUTING.md` §4).

About this guide

This page is the live view of the MedRisk design system. It is a static HTML/CSS file — no build step, no JavaScript — so it can be opened from disk or served from any static host. Every value shown here comes from frontend/src/styles/tokens.css; the components come from frontend/src/styles/components.css. Nothing is styled twice.

How to open it

cd frontend/styleguide and open index.html in a browser, or run python -m http.server 8000 --directory frontend/styleguide from the repository root.

Colour

One hue family (teal) for the brand and a warm amber-to-red ramp for the risk levels. Every token below has exactly one documented purpose; there are no "one-off" colours. The contrast ratio of each text pair is measured and published in design-system.md §2.2.

Risk levels

A risk level is never communicated by colour alone: each level carries a symbol and a text label, so the meaning survives a colour-vision deficiency, a greyscale print and a bright screen.

Typography

System font stack (--font-family-base): no web font is downloaded, so the first paint is never blocked by a network request. The base size is 16 px and is never reduced — the layout must stay usable at 200 % browser zoom.

Radius and elevation

--radius-md · 12 px

Cards use --shadow-md. Buttons and inputs use --radius-sm (8 px), badges and progress bars use --radius-full.

Focus indicator

Every interactive element gets a 3 px outline with a 2 px offset. The outline is never removed and never relies on box-shadow alone.

Components

The inventory below is the same list as in design-system.md §6. The React versions are produced in M4 (DIP-35 … DIP-38) and must consume the same tokens.

6.1 Button

One primary button per screen. The minimum target size is 44 px (--control-height-md). A disabled button stays in the DOM and is explained by a hint — it is not hidden. The loading state uses aria-busy="true" and keeps its width, so the layout does not jump.

6.2 Text field

In complete years, from 30 to 70.

The upper number, in mmHg.

Enter a number between 90 and 200. Example: 128

The value comes from your saved report.

Every field has a visible label; a placeholder is never the only label. The error message is below the field and connected with aria-describedby; the invalid field also carries aria-invalid="true" and a 2 px danger border, because the border alone is not enough.

6.3 Checkbox and radio

Do you smoke?
Optional measurements you want to include

The chip is the click target, the native control stays visible and keeps the selected state. A radio group is a fieldset with a legend: it is one tab stop and the arrow keys move inside it.

6.4 Card

Card title

Cards are the only container for grouped content on the report and the history screens. The background is the surface colour, the border is the decorative divider, the radius is 12 px and the elevation is --shadow-md.

6.5 Result table

Previous assessments. The change is written in words, not by colour alone.
Date Cardiovascular risk Diabetes risk Change
12 May 2026 14 % 9 % −1.3 pp (down)
12 February 2026 15.3 % 10 % — (first report)

The table is the accessible equivalent of the trend chart and is always present when the chart is shown. Column headers use scope="col", row headers use scope="row".

6.6 Disclaimer banner

This is a risk estimate, not a diagnosis. The number is calculated from the answers and measurements you entered. It cannot replace a consultation with a doctor.
This tool cannot tell you whether you are ill. Only a licensed physician can diagnose you and decide what to do. If you feel unwell, contact a doctor or an emergency service.
The numbers on this page are an illustrative example for the design review. They are not a result of the model.

Both disclaimer variants are mandatory on any screen that shows a risk number. The disclaimer is never inside a collapsible element, never shortened to an icon and never replaced by an image.

6.7 Risk badge

● Low risk ◆ Moderate risk ▲ High risk ■ Very high risk

The symbol is hidden from the screen reader, because the text label already carries the meaning. The border repeats the text colour, so the badge is still recognisable without the fill.

6.8 Progress indicator

5 of 12 questions answered · 3 of 8 required questions are still missing · 4 optional measurements can be skipped

The native progress element is used with max, value and aria-valuetext — the raw number "5" means nothing to a screen reader. The visible text repeats the same information in words.

6.9 Factor bar

High blood pressure
▲ increases the estimate · 88 % of the largest contribution in this example
Physical activity
▼ decreases the estimate · 31 % of the largest contribution in this example

The bar itself is decorative and hidden from assistive technology. The direction is always written as a word plus a symbol, and the magnitude is given in words.

6.10 Chart legend

  • Cardiovascular disease — solid line
  • Type 2 diabetes — dashed line

The legend states the line style, not only the colour, so the two series remain distinguishable in a greyscale print.

Accessibility rules

The design system targets WCAG 2.1 level AA. The rules below are not optional style preferences — a component that breaks one of them is a defect.

Accessibility contract of the MedRisk components.
Rule How it is implemented
Text contrast ≥ 4.5:1Measured for every token pair in design-system.md §2.2 — 30 of 30 pass.
UI boundary ≥ 3:1--color-border-strong on the surface (3.83:1) and on the page background (3.55:1).
Visible focus3 px outline with a 2 px offset on every interactive element; never removed.
No meaning by colour aloneRisk badge = symbol + text; deltas = word + number; chart legend = line style.
Programmatic names<label for>, <fieldset>/<legend>, aria-label.
Errors linked to the fieldaria-describedby + aria-invalid + an error summary above the form.
Landmarksheader, nav[aria-label], main, footer and a skip link.
Languagelang="en" on the root element of every page.
Chart text equivalent<svg role="img"> with <title>/<desc> plus a data table.
Reduced motionAll transitions are disabled under prefers-reduced-motion: reduce.
Target size ≥ 44 × 44 px--control-height-md on every control.
